# Vetrix 

A zero-dependency packet analyzer written in C from scratch.

## Features

- Read pcap (SLL2 only)

The project is still under development and currently supports only a limited number of protocols, so it cannot yet parse all network protocols.


## build 

clone the repo
```
git clone https://github.com/E-Vex/vetrix.git
```
build using make
``` 
make
```
